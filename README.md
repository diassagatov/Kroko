# Crocodile Party — Android Game

## Описание проекта

Crocodile Party — это мобильное приложение для командной игры в "Крокодил", созданное на Kotlin и Jetpack Compose. Приложение автоматизирует процесс разбиения игроков на команды, ведет отсчет времени на ход, выдает не повторяющиеся слова и считает очки до победы одной из команд.

## Архитектура и технические решения

- **MVVM Architecture**: Логика приложения полностью отделена от отображения. Управление состоянием происходит в `GameViewModel`.
- **Jetpack Compose & Material 3**: Интерфейс полностью декларативный, использованы стандартные компоненты Material 3 (Card, Surface, LazyColumn, Button).
- **Navigation Compose**: Навигация между экранами настроена через `NavHost` и `NavController` (всего 4 экрана: Setup, TeamPreview, Game, Scoreboard).
- **StateFlow & Coroutines**: Состояние игры передается в UI через `StateFlow`. Отсчет времени раунда реализован через корутины в `viewModelScope`.
- **Configuration Changes**: При повороте экрана счет, текущий ход и состояние таймера не сбрасываются благодаря хранению данных во ViewModel и поддержке `rememberSaveable`.

## Основной функционал

1. Добавление игроков и настройка количества очков для победы.
2. Автоматическое случайное распределение участников по двум командам.
3. Маскирование загаданного слова до запуска таймера игроком.
4. Отсчет 60 секунд на ход с визуальным предупреждением на последних секундах.
5. Исключение повтора слов до полного прохождения списка.
6. Экран результатов с автоматическим определением победителя.

## Инструкция по запуску

1. Открыть проект в Android Studio (версия Ladybug или новее).
2. Убедиться, что в проекте выбран JDK 17+.
3. Скомпилировать и запустить проект на эмуляторе или физическом устройстве (Android 8.0 / API 26 и выше).
